# SurgeBot для Android - сборка APK на GitHub

## Как собрать
1. Создайте на github.com новый репозиторий (можно приватный) и загрузите в него ВСЁ содержимое этой папки
   (вместе со скрытой папкой `.github`; проще всего через `git push`, веб-загрузка скрытые папки иногда пропускает).
2. Откройте вкладку **Actions** -> **Build APK** -> **Run workflow**. Первая сборка идёт 25-40 минут (скачивается Android SDK/NDK), следующие быстрее.
3. По окончании откройте запуск, внизу в **Artifacts** скачайте `SurgeBot-apk`, распакуйте, перенесите `.apk` на телефон и установите
   (разрешите установку из неизвестных источников). Если сборка упала, скачайте артефакт `buildozer-log` и пришлите мне лог.

## Как это устроено
- `service.py` - фоновая служба Android (foreground, с уведомлением): запускает бота и локальный сервер 127.0.0.1:8765.
  Бот живёт, пока служба работает, даже если окно закрыто.
- `main.py` - окно: запускает службу, кнопки "Открыть интерфейс" (встроенный WebView; назад - вернуться) и
  "Открыть в браузере" (Chrome, если WebView покажет ошибку), "Остановить службу и выйти".
- Остальные файлы - тот же бот, что на компьютере (демо и рабочий режим, настройки в интерфейсе).

## Важно
- Сборка подготовлена без возможности запустить Buildozer в среде разработки: возможны правки при первом запуске (это нормально для Kivy/Android).
- На Android 13+ разрешите уведомления для SurgeBot, а в настройках батареи выберите "Без ограничений" - иначе систему могут остановить службу.
- Начинайте с демо-режима. Рабочий режим: ключ Binance только Futures + Trading, без вывода, с привязкой к IP
  (у мобильного интернета IP меняется - лучше Wi-Fi со статичным IP). Прибыльность стратегии не доказана.
